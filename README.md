# FillWords PHC

Кроссворд «Филворды» для компании Bayer Consumer Health (Беларусь).

Игрок соединяет соседние буквы на сетке (вверх, вниз, влево, вправо; путь может изгибаться) и находит слова. В уровнях — названия препаратов Bayer и нейтральные слова о здоровье и жизни.

## Режимы

| Режим | Описание |
|-------|----------|
| **Кампания** | 18 уровней, сетки от 4×4 до 12×12 (по 2 уровня на размер) |
| **Челлендж дня** | Одна общая сетка на календарный день; 6×6 в будни, 7×7 в выходные |
| **Бесконечный** | Открывается после 18-го уровня; волны со случайными словами, сетка растёт до 10×10 |

## Прогресс

Сохраняется в `localStorage` под ключом `fillwords-phc-progress-v1`:

- пройденные уровни кампании;
- рекорд волн бесконечного режима;
- пройденные даты челленджа дня;
- звёзды (1–3) и лучшее время за уровни кампании;
- коллекция найденных препаратов Bayer;
- найденные слова и использованная подсказка в незавершённой сессии.

### Звёзды за уровень

| Звёзды | Условие |
|--------|---------|
| ★ | Уровень пройден |
| ★★ | Без подсказки |
| ★★★ | Без подсказки и в пределах лимита времени (зависит от размера сетки) |

## Стек

- React 18 + TypeScript (strict)
- Vite
- React Router
- Vitest

## Структура

```
src/
  app/          — маршруты и композиция приложения
  domain/       — чистая логика пазлов (сетка, слова, проверка, прогресс)
  features/     — экраны и UI-фичи
  shared/       — переиспользуемые UI-компоненты и утилиты
  styles/       — глобальные стили и токены
  dev/          — dev-only хелперы (не попадают в production-сборку по смыслу)
```

## Команды

```bash
npm install
npm run dev
npm run build
npm test
```

## Деплой на Vercel

Приложение можно деплоить как одну сборку с маршрутами `/bayer` и `/egis` или как две отдельные версии из одного репозитория.

Для отдельных Vercel Project задайте переменную окружения:

- Bayer: `VITE_BRAND=bayer`
- EGIS: `VITE_BRAND=egis`

Если `VITE_BRAND` задан, корень сайта и неверные бренд-маршруты будут вести на выбранную версию. Если переменная не задана, по умолчанию открывается Bayer, но оба маршрута остаются доступны.

## Разработка

В dev-режиме можно быстро открыть бесконечный режим:

```
http://localhost:5173/?unlock=infinite
```

Параметр работает только при `npm run dev` и помечает все 18 уровней пройденными.
