# FillWords PHC

Кроссворд «Филворды» для PharmConsilium.

## Стек

- React 18 + TypeScript (strict)
- Vite
- React Router

## Структура

```
src/
  app/          — маршруты и композиция приложения
  domain/       — чистая логика пазлов (сетка, слова, проверка)
  features/     — экраны и UI-фичи
  shared/       — переиспользуемые UI-компоненты и утилиты
  styles/       — глобальные стили и токены
```

## Команды

```bash
npm install
npm run dev
npm run build
npm test
```
