# FillWords Bayer

Отдельный проект филвордов для компании Bayer Consumer Health.

Игрок соединяет соседние буквы на сетке и ищет названия лекарственных препаратов Bayer. В уровнях также используются нейтральные слова о здоровье и жизни.

## Бренд

Проект закреплен за Bayer:

- `npm run dev` запускает Vite в режиме `bayer`;
- `npm run build` собирает production-версию Bayer;
- брендовая конфигурация находится в `src/brands/bayer`.

## Команды

```bash
npm install
npm run dev
npm run build
npm test
```

## Стек

- React 18 + TypeScript
- Vite
- React Router
- Vitest
