# FillWords EGIS

Отдельный проект филвордов для компании EGIS.

Игрок соединяет соседние буквы на сетке и ищет названия лекарственных препаратов EGIS. В уровнях также используются нейтральные слова, связанные с имиджем компании.

## Бренд

Проект закреплен за EGIS:

- `npm run dev` запускает Vite в режиме `egis`;
- `npm run build` собирает production-версию EGIS;
- брендовая конфигурация находится в `src/brands/egis`.

## Команды

```bash
npm install
npm run dev
npm run build
npm test
```

## Стек

- React 18 + TypeScript
- Vite
- React Router
- Vitest
